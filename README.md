# Pokewwwww

A Pokémon trivia web app with eight game modes:

| Mode | Route | What you do |
|---|---|---|
| **Name 'Em All** | `#/timed` | Name as many Pokémon as you can before the timer runs out (optional easy mode accepts one-letter typos) |
| **Who's That?** | `#/guess` | Guess a hidden Pokémon; each guess shows which of 9 attributes match |
| **Pokédle** | `#/wordle` | Wordle with Pokémon names; pick a length from 4 to 11 letters |
| **Pokécross** | `#/crossword` | Solve a generated crossword of Pokémon names |
| **Silhouettes** | `#/silhouette` | Name a Pokémon from its shadow: Pokémon of the day (3 tries) or a timed run by region |
| **Cries** | `#/cry` | Name a Pokémon from its cry: Pokémon of the day (3 tries) or a timed run by region |
| **Moveset** | `#/moveset` | Name a Pokémon from the moves it learns; each miss reveals another move |
| **Hangman** | `#/hangman` | Guess a Pokémon name letter by letter; 6 misses allowed |

Who's That?, Pokédle, Pokécross, Moveset and Hangman also have a daily puzzle (the same for everyone) and an unlimited mode. There is also a contact page (`#/contact`).

The original design is in [BLUEPRINT.md](BLUEPRINT.md).

## Develop

```powershell
npm install
npm run dev      # http://localhost:5173
npm test         # vitest
npm run build    # static site in dist/
npm run preview  # serve dist/ locally
```

Everything runs in the browser; there is no backend. Progress and stats are saved in `localStorage`.

## Data

`src/data/pokedex.json` is generated by `npm run data` from [PokeAPI](https://pokeapi.co) and
[PokéSprite](https://github.com/msikma/pokesprite). It is committed, so builds don't need network access.

- Raw API responses are cached in `scripts/cache/` (gitignored), so re-runs don't hit PokeAPI again.
  Delete that folder to force a fresh fetch. `npm run data -- --limit 151` does a quick partial build.
- Sprites load from a pinned PokéSprite commit (`src/data/sprites.ts`). Gen 9 isn't in PokéSprite,
  so those use PokeAPI's sprites.
- `src/data/movesets.json` (Moveset game) is generated by `npm run data:moves`, run after `npm run data`.
  For each Pokémon it picks 6 moves from its most recent level-up set, ordered from common to rare,
  with the level (or TM / tutor / egg) it learns each one at and the game those levels come from.

## Deploy

The build is a static folder with relative paths and hash routing, so it works on any static host
and from any sub-path.

- **GitHub Pages:** push to `main` with `.github/workflows/deploy.yml` in place, then set
  *Settings → Pages → Source* to **GitHub Actions**. The workflow runs the tests, builds, and publishes.
- **Netlify / Vercel / Cloudflare Pages:** build command `npm run build`, output directory `dist`.

## Code map

```
scripts/build-pokedex.ts   data pipeline
src/data/                  Pokédex JSON, types, lookups, sprite URLs
src/lib/                   pure game logic (all unit-tested): name matching, RNG, scoring, crossword generator
src/components/            shared UI: Sprite, TypeBadge, PokemonInput, Keyboard, Timer, FilterPanel, ShareButton
src/games/<mode>/          each mode's screens and Zustand store
```
